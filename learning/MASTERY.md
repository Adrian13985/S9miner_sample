# 掌握度账本

## 等级定义

| 等级 | 含义 | 合格证据示例 |
|---|---|---|
| L0 未形成 | 尚未接触，或只有文件存在 | 无 |
| L1 熟悉 | 在提示下能识别术语和复述局部过程 | 带提示解释、跟做成功 |
| L2 独立复现 | 无参考资料能完成最小实现并解释主要因果链 | 闭卷重写、独立搭建、预测结果正确 |
| L3 迁移与调试 | 约束改变后仍能设计；能从现象定位故障层 | 近迁移、故障注入和定位记录 |
| L4 综合设计 | 能比较方案、量化权衡并完成跨层验证 | 设计说明、测量数据、远迁移或综合项目 |

跑通参考例程最多只能支持 L1。AI提示下完成的任务要标记为“辅助”，不能替代无提示证据。

### 2026-09-21 / P02 UART / 轮询与阻塞故障注入

- 辅助程度：部分脚手架；AI 修改和恢复源码，学习者完成构建、下载和上板观测
- 预测：无条件调用 `inbyte()` 且无输入时，周期打印停止
- 实际结果：启动只打印 `count = 0`；每输入一个 `i` 才前进一步，`Current count` 始终为 1；恢复轮询保护并重建 ELF 后周期打印恢复
- 因果解释：当前应用由 CPU 轮询 UART 状态；`XUartPs_RecvByte()` 在 RX FIFO 为空时阻塞，同一执行流无法执行 `elapsed_ms` 和周期打印逻辑
- 可复查证据：`learning/evidence/P01_UART/2026-09-21_blocking_fault_observation.md`
- 暴露的误区：首次闭卷把轮询说成中断；混淆 C 对象与外设寄存器，以及 `p`、`*p`、`&p`
- 建议等级：保持 L1；本次不是无提示独立实现
- 延迟复测条件：隔日闭卷路径图和指针题；之后无参考重写最小命令循环

### 2026-09-22 / P03 PS GPIO / 寄存器追踪与近迁移

- 辅助程度：先讲解寄存器模型，再以问题提示完成多轮即时迁移
- 实际结果：正确推导 GPIO69/70 的 LSW/MSW 地址和写 1 数值；经一次纠正后完成 GPIO70/71 同寄存器多位掩码写；能解释跨寄存器写的中间状态、DATA 锁存与 DIRM/OUTEN 分层，以及高/低有效 LED 的安全初始化顺序
- 因果解释：Bank 选择寄存器组，LSW/MSW 选择半区，高 16 位低有效掩码决定哪些低 16 位数据生效；DATA 可先锁存，DIRM 选方向，OUTEN 最后接通物理输出驱动
- 可复查证据：本次问答；BSP `gpiops_v3_3/src/xgpiops.c`、`xgpiops_hw.h`
- 暴露的误区：曾混淆 Bank 内 bit 与寄存器内部数据位、把相邻地址理解为一次写入、认为 OUTEN=0 会阻止 DATA 更新；本轮 DIRM/OUTEN 控制位换算答错并已讲解，待闭卷确认
- 建议等级：保持 L1；当前证据为引导后的即时迁移，不替代延迟闭卷复测
- 延迟复测条件：按用户安排于 2026-09-22 晚间完成 GPIO 综合短复测
- 当次未计入已学内容：DIRM/OUTEN 的读—改—写及并发丢失风险仅开始讲解，用户因疲劳停止；后续学习证据见下一条记录

### 2026-09-22 / P03 PS GPIO / DIRM/OUTEN 读—改—写与并发

- 辅助程度：问题提示后讲解；临界区伪代码由 AI 给出，学习者完成数值迁移但未独立重建完整接口
- 预测与结果：闭卷确认 GPIO70 为 Bank 2/bit 16、使用 DATA_MSW；经一次编码纠正后独立算出 GPIO71 清零值 `0xFFFD0000`；能算出 `0x05` 设置 bit 3 后为 `0x0D`，以及 `0x12` 同时置 bit 3、清 bit 4 后为 `0x0A`
- 因果解释：能说明 DATA Mask 位允许单次按位写，而 DIRM/OUTEN 需保留共享寄存器其他位；理解旧快照写回会覆盖中断刚完成的更新，并判断 `volatile` 不能提供原子性
- 暴露的缺口：曾把 bit 5/bit 3 的掩码误写成 `0x05/0x03`；曾认为中断应保护到主循环结束；最终伪代码仍残留上一题的 `DIRM`、单 bit 参数或多余 `output` 分支
- 可复查证据：`learning/evidence/P02_GPIO/2026-09-22_rmw_concurrency_lesson.md`
- 建议等级：保持 L1；本次为引导式即时迁移，不足以证明无提示独立复现
- 延迟复测条件：下一次会话闭卷写出 OUTEN/DIRM 任一寄存器的双位更新、保存/恢复中断状态，并解释临界区边界

## 更新规则

- 每次提升等级必须附上日期、任务、辅助程度和可复查证据位置。
- “我感觉懂了”记录为信心，不记录为掌握等级。
- 如果延迟复测失败，保留历史最高证据，同时把“当前可调用水平”下调并加入复习队列。
- 同一例程的重复不能证明迁移；至少改变一个重要约束。
