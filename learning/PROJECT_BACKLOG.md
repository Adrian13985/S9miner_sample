# 项目库：P00–P40

项目编号表达能力递进，不等于必须机械线性完成。每个项目开始前先检查 `CURRICULUM.md` 中的先修节点；结束时必须留下源码、构建方法、预测、观测、故障注入和迁移证据。现有四个工程只是 P01–P04 的素材，不是路线边界。

## 统一验收格式

每个项目至少回答：

1. 数据或信号从哪里来，经过哪些硬件/软件层，到哪里可观测；
2. 哪些是本板实测，哪些来自文档，哪些仍是假设；
3. 主动制造一种失败并定位到正确层；
4. 不看原实现，完成一个改变接口、时序、容量或执行方式的迁移任务；
5. 记录源码、日志、波形、报告和版本来源。

风险等级沿用 `research/BOARD_CAPABILITY_MATRIX.md`：S0 为安全入门，S1 为受控实验，S2 需电气核验，S3 需备份与恢复。

## 如何选下一个项目

1. 在 `MASTERY.md` 找到影响当前目标的最低级先修节点。
2. 在本文件中选能产生该节点独立证据的最小项目，而不是选看起来最酷的项目。
3. 如果项目跨越多个 L0 节点，拆小；如果只是重复同一例程，增加迁移或故障条件。
4. 高风险项目必须同时满足电气核验、恢复路径和停止条件。
