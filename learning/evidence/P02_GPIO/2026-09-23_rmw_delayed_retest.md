# 2026-09-23 P02 GPIO 读—改—写延迟复测

- 辅助程度：先闭卷回答，随后分步纠正并进行一次改变数值和寄存器的近迁移
- 首次题目：对 `DIRM=0x21`、主循环清 bit 5、中断置 bit 3，最初把错误中间值写为 `0x29`；分步后能正确得到 `0x21 -> 0x01 -> 0x09`
- 临界区：能写出保存并禁止中断、读、修改、写的主体，并能解释进入前可能已经禁止中断；但两次都写成 `restore_irqs(enable)`，没有把保存的 `irq_state` 传回恢复函数
- 迁移题：对 `OUTEN=0x14`、主循环置 bit 1、中断清 bit 4，回答正确终值 `0x05`、错误终值 `0x15`；正确结果应分别为 `0x06` 和 `0x16`
- 模板残留：迁移题要求操作 `OUTEN`，伪代码仍调用 `read_dirm/write_dirm`；位操作表达式 `1U << 1` 本身正确，但手算结果把 bit 1 当成了 bit 0
- 并发理解：能说出 `volatile` 后主循环仍可能覆盖更新，但尚未稳定表述“volatile 不使整个读—改—写原子化，也不阻止中断插入”
- 建议等级：P03 PS GPIO 保持 L1；延迟近迁移未通过
- 延迟复测：先完成位号、单 bit 掩码、置位/清位的无并发专项；通过后再做 OUTEN 双参与者交错和保存/恢复中断状态，不沿用 DIRM 模板
