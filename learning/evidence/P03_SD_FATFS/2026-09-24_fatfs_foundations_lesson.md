# 2026-09-24 P03 SD/FatFs 基础课

- 课程节点：C01/C06、B00/B01
- 性质：引导式基础课与即时验收；尚未修改代码、构建或上板
- 风险：S0，只读审计；原始越界版本未运行
- 来源：本地 SDK 2017.4 BSP，`xilffs_v3_7`（FatFs R0.10b）、`sdps_v3_3` 和当前 P03 源码
- 已建立分层：应用缓冲区 → FatFs 文件/簇/部分扇区缓冲 → `diskio` 扇区接口 → `XSdPs_*Polled` → ADMA2 → PS SD 控制器/MIO → SD 卡
- 已建立 API 模型：能区分 `FRESULT` 与 `br/bw`、EOF 正常短读与短写、`f_sync` 与 `f_close`、覆盖/打开/追加语义、`FATFS` 与 `FIL` 生命周期
- 已建立容量模型：能判断应用不需补齐 512 字节扇区；能说明扩大请求长度不会扩大源数组，越界读取可能在裸机地址空间中静默读取相邻数据
- 已建立验证模型：关闭后重新打开，检查 `br == len`，再用 `memcmp(src, dest, len)` 做逐字节验证；知道 `%s` 会在首个 `\0` 停止，不能证明文件尾部无垃圾
- 即时验收表现：在纠正后能判断短读/短写、打开后清理、对象失效、分层职责、输出参数和缓冲区终止位置
- 暴露的缺口：首次把 EOF 短读与短写对调；曾把部分扇区转换归给 `diskio`；曾认为关闭后的 `FIL` 可继续写；完整流程重建时混入追加/日志步骤；出口题曾把 `br=10` 误作有效长度 9，定点纠正后能答出 `br=3` 对应长度3、下标0–2、终止符下标3
- 建议等级：B00、B01 提升到 L1；证据为直接讲解和即时迁移，不支持 L2
- 延迟复测：下次开场无提示区分 EOF 短读、短写与错误，并独立写出覆盖写入—关闭—重开—回读校验流程；之后才在工程副本中实现
